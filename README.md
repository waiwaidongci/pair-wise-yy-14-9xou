# hxyfront-62013 木结构榫卯构件测绘 · 版本放行台

源提示词编号：8

古建筑木结构榫卯构件测绘前端。测绘页即版本放行台：补测提交后先判定、再存档，最新有效版生成修缮建议并进入施工清单，旧截面尺寸转入替换件下料。

## 业务代码三处分离

| 职责 | 位置 | 说明 |
| --- | --- | --- |
| 判定 | `src/domain/judgment.ts` | 补测判校（截面非正 / 病害位置越界 / 补测时刻早于上一版）、修缮建议生成、施工清单口径 |
| 存档 | `src/data/archive.ts` | localStorage 持久化、版本落库：构件编号全库唯一；判定通过则旧版转历史、新版放行，不通过则保留原记录、新版挂待复核 |
| 页面操作 | `src/App.tsx` + `src/components/*` | 放行台表单、构件清单、历史版本、尺寸记录表、病害标记图、构件关系视图、施工清单 |

## 功能

- 新增测绘 / 补测：记录榫卯类型、截面尺寸、病害位置（沿构件 0–100%）、变形量、补测时刻；构件编号不重复，命中已有编号自动记为补测新版
- 判定不通过（截面非正、位置越界、补测早于上一版）→ 保留原记录，新版挂待复核
- 最新有效版生成修缮建议并进入施工清单；变形 ≥20mm 建议替换，旧截面进入下料
- 待复核版本在构件清单与关系图中标出冲突
- 按榫卯类型筛选（燕尾榫 / 透榫 / 半榫 / 箍头榫 / 管脚榫 / 馒头榫），可查每构件历史版本
