# hxyfront-62013 木结构榫卯构件测绘 · 版本放行台

源提示词编号：8

古建筑木结构榫卯构件补测测绘前端。测绘页是「版本放行台」：补测登记先过判定，
放行后旧截面进入替换件下料、最新有效版生成修缮建议并进入施工清单；判定未过挂起
待复核，原记录保留，并在构件清单与关系图中标出冲突。

## 三处业务代码

业务判定、存档、页面操作严格分到 `src/domain/` 三个模块：

| 模块 | 职责 |
| --- | --- |
| `domain/judge.ts` | **判定**：截面非正 / 病害位置越界 / 补测时刻早于上一版；修缮建议生成；清单、指标、关系图等读模型（纯函数，不碰存档） |
| `domain/archive.ts` | **存档**：版本台账、localStorage 持久化、旧版置 `superseded`、旧截面推替换件下料单、待复核驳回留痕 |
| `domain/operations.ts` | **页面操作**：表单解析与校验、补测预填、提交/驳回动作、`useStation` 订阅绑定 |

## 版本规则

- 构件编号不重复；同一编号再次登记即视为补测，编号锁定并沿用上一版档案。
- 新增测绘必填：榫卯类型、截面尺寸（宽×高 mm）、构件总长、病害位置（距端部 mm）、
  变形量、补测时刻。
- 判定规则（任一不满足则不放行，登记为 `pending`，原有效版保留）：
  - 截面宽、高须为正数；
  - 病害位置须在 `0 ~ 构件总长` 之间；
  - 补测时刻须晚于上一版（驳回记录不参与比较）。
- 放行：生成修缮建议并进入施工清单；若存在上一有效版，旧截面尺寸写入替换件下料单，
  上一版标记为「已替代」。
- 待复核版本在构件清单（红行 + ⚠）和单栋建筑关系图（红框节点）标出冲突；
  复核可驳回并留痕，驳回记录仍保留在历史版本时间线中。
- 按榫卯类型筛选构件与施工清单；展开构件行可查全部历史版本（状态、补测时刻、尺寸）。

## 技术栈

React 19 + Vite + TypeScript，无后端，台账存 localStorage（内置演示数据可一键恢复）。
